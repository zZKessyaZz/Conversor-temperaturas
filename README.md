# Conversor-temperaturas
Projeto para converter temperaturas (Celsius, Fahrenheit e Kelvin)

Este projeto foi feito com o Tkinter.
De forma simples e intuitiva, ele converte as temperaturas (Celsius, Fahrenheit e Kelvin) e mostra o resultado. 
Existem duas spinboxes para selecionar qual é a escala termométrica, um botão de converter e outro  botão para copiar e uma confirmação de 
cópia, e também há um aviso se não houver nada para copiar.
O programa avisa quando a entrada não é um número e mostra a mensagem de Valor Inválido.
